# Website content you can edit

The website (https://deploy-eu.github.io) reads the files in this folder every time someone opens it. Edit them right here on GitHub (pencil icon → Commit changes); the site shows the change within a minute or two. No code involved.

- `events/` — one file per event. Copy an existing file, change the fields, commit. Past events can stay; the site sorts them by date and shows upcoming ones first. Use `date: "TBA"` while the date is not fixed.
- `open-roles.md` — the roles we are looking for, shown on the Join page. One line per role: `- **Role name**: what it involves`.

Write in English. Keep it short; the website adds the layout.
