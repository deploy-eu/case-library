# Deploy@EU 案例库

**欧洲企业里 AI 落地的真实案例，由亲手做的人来写。**

Deploy@EU 是一个非营利社区，成员是在欧洲企业里做 AI 和自动化落地的人：前线部署工程师（FDE）、企业内部的开发者、顾问，以及和他们一起做事的企业主。这个仓库是我们共同的落地案例库。

主要语言是英文；用中文或你的母语写也可以，维护者会帮忙补一段英文摘要。

## 每个案例回答这些问题

- 什么业务问题，哪个行业，哪个国家？
- 原来有哪些系统，加了哪些 AI 工具？
- 现在的流程是什么样？
- 改变了什么？只写量过的，估计的要标明。
- **卡在哪？** 没有接口的老系统、合规、人、数据质量……
- 重来一次会怎么做？

## 怎么参与

看 [CONTRIBUTING.md](CONTRIBUTING.md)。简单说：

1. 复制 [`cases/_TEMPLATE.md`](cases/_TEMPLATE.md) 填好提交；不用 Git 的，开一个「Case submission」issue，或者把内容交给任何一位维护者。
2. 维护者审一遍：有没有脱敏、有没有得到同意、数字是否老实、有没有广告。
3. 合并后，你会出现在贡献者名单里。

还没准备好写完整案例，也可以：推荐一位访谈嘉宾、给已有案例纠错补充、或者说说你撞过的一堵墙。

## 规矩一段话

这里是社区，不是市场。社区不为任何企业背书，包括赞助方和成员自己的公司。案例写做了什么、结果如何，不是产品介绍，不写价格和销售联系方式。个人数据和保密信息不进来。详见 [GOVERNANCE.md](GOVERNANCE.md)、[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md)、[RECOGNITION.md](RECOGNITION.md)。
