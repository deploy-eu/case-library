# Tools

Open-source tools from members, listed with a short card. The code lives in the author's own repository; this folder only holds the cards. The website reads them automatically and shows each tool under the walls it helps with.

Add a card: copy [`_TEMPLATE.md`](_TEMPLATE.md) to `tools/<your-github-handle>/<tool-name>.md`, or open a **Tool** issue and paste the details.

Rules (also in [CONTRIBUTING.md](../CONTRIBUTING.md#share-a-tool)):
- Open source with a recognised licence, free to use. No paid products, no "free trial" SaaS, no lead forms.
- The repository is public and has a README that explains how to start.
- No personal or client data in the repository, not even in examples.
- Say who maintains it. Tools nobody maintains for a year are marked "archived", not removed.
